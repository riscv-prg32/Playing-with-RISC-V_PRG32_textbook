# Publishing example

Files used by the chapter "Publishing Cartridges on the Cartridge Store".

- `manifest.json` — the bundle manifest (`prg32-metadata-1.0`). Change `id`,
  `authors`, and `version` before a real submission.
- `colophon.json` — the credits screen (`prg32-colophon-1.0`).
- `icon.png` — supply your own PNG icon next to the manifest.

The scripts under `../../scripts/store/` build, pack, and submit the bundle.
