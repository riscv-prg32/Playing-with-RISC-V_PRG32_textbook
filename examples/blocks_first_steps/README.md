# Blocks first steps

Projects for the Young Makers track (PRG32 Construction Kit, ages 7+).

Each `*.blocks.json` file is a Construction Kit project: open the Kit, choose
**Import JSON**, and pick the file. Each `*.c` file is the C source the Kit's
**Generate C** button produces for that project, kept here so that the C and
assembly tracks can read it without running the Kit.

| Mission | Project | Idea |
| --- | --- | --- |
| 1 | `first_square` | start, draw, coordinates |
| 2 | `moving_square` | buttons, variables, staying on screen |
| 3 | `lemon_catcher` | falling object, touching, random, score bars |
| 4 | `music_pad` | notes, one button per sound |

`../complete/lemon_catcher_c_game.c` is the same game written by hand in C.
